# 语料台账 · Corpus Ledger

> 澈思（Chesi）AI 的全部训练语料，按用途分组，逐条登记**来源 / 许可 / 体量 / 准入等级**。
> 准入等级定义（A=宽松可商用、B=有条件、排除=不可用）见 `dataset_acquisition/LICENSE_AUDIT_20261021.md`。
> **本页只登记公开可查的语料**；内部文件级索引（809 文件 / 58.5 GB）保留在项目内部，不公开本地路径结构。
> 原则：① 基座语料只用**可商用的开源人类语料** ② **不使用任何外部模型生成的数据**（蒸馏禁令） ③ 每条数据都能指到公开来源

---

## 0. 许可等级速查

| 等级 | 含义 | 用法 |
|---|---|---|
| **A** | 宽松许可（MIT / Apache-2.0 / CC-BY 等），可商用 | 可直接进训练 |
| **B** | 有条件（自定义协议 / 逐项核实 / 仅研究用） | 商用前需单独处理，训练中仅用其 A 级子集 |
| **排除** | 传染性或禁止性许可（如 CC-BY-SA 混入 Apache-2.0 项目） | **不得进任何训练集** |

## 5. 数据准入四原则（项目自述）

1. **基座语料**：只用可商用的开源人类语料，按来源逐条登记许可与等级（License Ledger）
2. **蒸馏禁令**：不允许用外部模型生成数据训练自己的模型；外部模型仅作评测参照
3. **SFT / 人格 / 七步链**：永远纯人工 + 自有模型 STaR 自产
4. **诚实陈述**：所有数字带口径（样本量 / 时间 / 来源）；未实测项明确标注「未实测」
