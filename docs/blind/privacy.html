隐私说明

本页说明「看图猜 AI」这个小测试收集了什么、没收集什么。最后更新 2026-10-28。
一句话：页面上什么数据都不会发到任何服务器。
你的答案只存在你自己手机浏览器的内存里，做完当场算成一串短码， 由你自己复制后发给发起人。关掉页面，数据就没了。

1. 收集的信息

项目是否收集说明
你的 84 个答案（A / R）是（仅本地）存在浏览器内存里，用来在你手机上算出短码
每题的思考耗时是（仅本地）用于判断有没有认真看图，不离开你的设备
昵称可选只是为了让发起人区分是谁交的，随便写、不写也行
姓名 / 手机号 / 邮箱不收集页面上根本没有这些输入框
IP / 设备型号 / 位置不收集没有统计代码，没有后端接口
Cookie / 本地存储 / 缓存不使用没有 cookie、localStorage、sessionStorage

2. 页面上那个脚本在做什么

页面里有一小段内嵌 JavaScript，它只做四件事：

  • 记下你点了 A 还是 R（存在内存变量里）
  • 算进度条该走到哪
  • 答完后把那 84 个 0/1 压成一串约 20 字符的短码（含校验和）
  • 把短码复制到你的剪贴板（只在你自己点「复制」按钮时才做）

它没有任何 fetch / XMLHttpRequest / sendBeacon 调用， 不会向任何服务器发送数据，不会读取你的通讯录、相册、定位、剪贴板内容。

3. 一次完整使用的网络请求清单

实测（清空缓存后完整答完 84 题）：
总请求 85 次 = 1 个 HTML + 84 张图片
全部是 GET，全部指向 chesi-ai-models.github.io
零第三方请求：没有 Google Analytics、没有百度统计、没有广告 SDK、没有字体 CDN

4. 短码是怎么保证不乱码的

84 个答案按位压成 11 字节，加 1 字节长度、1 字节校验和，再做 base64url 编码。 总共约 20 个字符，微信里发不会断行。

因为带校验和，少复制一个字符会立刻报「校验失败」，不会静默算错。

短码里只有那 84 个 0/1，不含任何身份信息。

5. 发起人拿到之后会怎么用

  • 只用于统计「普通人能不能分辨 AI 生成图与真实照片」这一个问题
  • 只汇总出识别率与置信区间，不公开任何单个人的答题明细
  • 不会用于商业推广、不会转卖给第三方、不会用于训练模型

6. 想撤回怎么办

因为没有账号、没有后端、没有数据库，只要不把短码发出去， 发起人就完全不知道你做过这个测试。发出去之后想让数据作废，直接告诉发起人即可。
