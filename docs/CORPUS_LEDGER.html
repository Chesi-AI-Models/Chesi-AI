0. 许可等级速查

等级含义用法
A宽松许可（MIT / Apache-2.0 / CC-BY 等），可商用可直接进训练
B有条件（自定义协议 / 逐项核实 / 仅研究用）商用前需单独处理，训练中仅用其 A 级子集
排除传染性或禁止性许可（如 CC-BY-SA 混入 Apache-2.0 项目）不得进任何训练集

5. 数据准入四原则（项目自述）

  1. 基座语料：只用可商用的开源人类语料，按来源逐条登记许可与等级（License Ledger）
  2. 蒸馏禁令：不允许用外部模型生成数据训练自己的模型；外部模型仅作评测参照
  3. SFT / 人格 / 七步链：永远纯人工 + 自有模型 STaR 自产
  4. 诚实陈述：所有数字带口径（样本量 / 时间 / 来源）；未实测项明确标注「未实测」
