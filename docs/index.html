训练损失曲线

两个口径，别混：曲线是训练期内记录的 eval（末点 1.3694 @ step 20,000）； 上表的验收 eval 1.5618 是 verify_stage1.py 的独立复评（32-block held-out）。 两者口径不同，但都满足 ≤1.8。
诚实记录：严格的「每窗不增」判据在 full run 上微升 0.16%（落在收敛噪声地板内）， 因此我们同时保留趋势式判据并双判据并存，而不是把失败藏起来。

三个硬指标（可测，不是口号）

① 无提示词自主七步思维链

目标：把七步推理结构训练进权重，推理时不再拼提示词模板。

路径：自有模型 STaR 自蒸馏（生成 → 答案过滤 → 再训，用自己的模型当老师，不碰蒸馏禁令）。

现状：推理引擎仍是提示词注入式（level≥2 拼接七步标题），隐式化待 Stage-2（1B）跑通后启动。

② 无 AI 味

真人写实金标 + 偏好对 DPO + 盲测 KPI。

当前口径：真人参照分布分位数 + 盲评识别率（≥5 名独立评者）。

③ 反脸模

跨种子 ArcFace 余弦可测量上限，同一提示词无限次生成不出现同一张脸。

03数据准入原则

我们对自己也严格 —— 这是「从零」这两个字的全部代价。

基座语料

只用可商用的开源人类语料，按来源逐条登记许可与等级（License Ledger）。

蒸馏禁令

不允许用外部模型生成数据训练自己的模型；外部模型仅作评测参照。

SFT / 人格 / 七步链

永远纯人工 + 自有模型 STaR 自产。

诚实陈述

所有数字带口径（样本量 / 时间 / 来源）；未实测项明确标注「未实测」。

许可等级速查

等级含义用法
A宽松许可（MIT / Apache-2.0 / CC-BY 等），可商用可直接进训练
B有条件（自定义协议 / 逐项核实 / 仅研究用）商用前需单独处理，训练中仅用其 A 级子集
排除传染性或禁止性许可（如 CC-BY-SA 混入 Apache-2.0 项目）不得进任何训练集

04快速开始（复现 Stage-1）

完整步骤见 docs/REPRODUCE.md：含语料获取与许可确认、parquet→jsonl 转换、验收口径，以及「哪些性质保证可复现、哪些绝对值会因语料不同而变」的诚实边界。

# 依赖：torch（CUDA 或 CPU 均可），其余为 Python 标准库
python stage1/train.py --corpus <你的语料路径> --steps 20000 --device cuda

# 四判据验收（②③④ 硬判据，① full run 才判定）
python stage1/verify_stage1.py --mode full
设备无关：没有 CUDA 也能跑（--device cpu），只是慢。
