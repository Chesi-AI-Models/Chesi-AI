# Chesi AI（澈思）

**从零训练的中文人格化多模态小模型** · 自训 tokenizer · 自训基座 · Apache-2.0

> 一个独立开发者从零开始的公开实验：不用任何外部模型当基座，不用任何模型生成训练数据，
> 全部代码、语料准入口径与训练日志公开可查。

---

## 这是什么

澈思（Chesi）是一个**中文人格化**的多模态小模型。与常见的「在开源基座上做 LoRA」不同，
澈思的基座**从零预训练**：自训 tokenizer、自训模型结构、自建训练器、自管语料准入。

理由很直接：**人格核的出身必须是干净的。** 如果基座带着别人的先验、
如果人格数据是另一个模型生成的，那么"这个模型是谁"这个问题永远说不清楚。
我们选择慢的那条路。

## Stage-1 已跑通并验收（2026-10-23 实测）

从零预训练的第一级（13.6M 参数级）的完整一次 full run，实测数据如下：

> ℹ️ 本级用的是**英文推理语料**（OpenThoughts3 + SmallThoughts，见下方语料说明）；中文基座语料走路线图 Stage-2。

| 指标 | 实测值 | 口径 / 判据 |
|---|---|---|
| 唯一参数 | **13,639,680** | 6 层 / d=384 / 8 头 / seq 512，tied head 去重 |
| 训练步数 | **20,000 步** | batch 4 · seq 512 · lr 6e-4 |
| 训练耗时 | **26.1 分钟** | 单张 RTX 4080，13 步/秒 |
| **eval loss** | **1.5618** | 判据 < 1.8 —— **首次达标** |
| 数值一致性 | 相对差 **1.85e-07** | 与独立手写参考实现（朴素注意力/LN/GELU/CE 循环）对比，阈 15% |
| 可复现性 | **bitwise 完全一致** | 同种子两次运行，逐步损失逐位相同 |
| 收敛趋势 | 首尾 **2.6436 → 1.3732**（降幅 48.1%） | 14 个窗口中仅 2 次回升，落在收敛噪声地板上 |

![Stage-1 训练损失曲线](docs/stage1_loss_curve.svg)

> **图注（两个口径，别混）**：曲线是**训练期内记录**的 eval（末点 **1.3694** @ step 20,000）；
> 上表的验收 eval **1.5618** 是 `verify_stage1.py` 的**独立复评**（32-block held-out）。
> 两者口径不同，但**都满足 ≤1.8**。绘图脚本 `scripts/plot_stage1_curve.py`（零依赖，纯标准库，可复现）。

> **诚实记录**：严格的「每窗不增」判据在 full run 上微升 0.16%（落在收敛噪声地板内），
> 因此我们同时保留**趋势式**判据并双判据并存，而不是把失败藏起来。
> 详见 `stage1/README.md` §4。

**训练语料（Stage-1）**：OpenThoughts 1,200,000 行 + SmallThoughts 102,000 行。
⚠️ 这两套是**英文推理语料**，在澈思的路线里只作**推理能力增强组件**，不是中文基座主粮；
中文基座语料来自 SkyPile-150B（head 层，已落地 61GB / 39 分片），准入口径见下。

**Tokenizer**：自训 v1.1，字符级双档 —— Stage 1 词表 7,276 / 全量 11,387，
四大数据集往返一致性 100%。

**设备无关**：设备探测链 `cuda → npu → xpu → musa → cpu`；CPU 与 CUDA 通道在 bs=4 下曲线差 <0.4%（实测）。
⚠️ **昇腾 910B / C500 / BI-V100 尚未实测**——device 链已就绪，实际验证随启智社区三级冒烟进行。

## 路线图

| 阶段 | 目标 | 状态 |
|---|---|---|
| Stage-1 | 10M 级从零预训练，验证收敛与数值正确性 | ✅ 已验收（见上表） |
| Stage-2 | **澈思-1B** 从零预训练（中文基座语料为主） | 🔄 语料**已下载**（SkyPile-150B head 层 61GB / 39 分片），token 统计与准入审计进行中 |
| Stage-3 | 自训基座 + 自有人格 SFT（目标 50 万条；候选池 80.6 万，配比与筛选待冻结） | ⏳ |
| Stage-4 | DPO / RL：情境感知诚实策略 | ⏳ |
| Stage-5 | 多模态：图像生成 + 反脸模 + 无 AI 味 | ⏳ |

**三个硬指标**（可测，不是口号）：
1. **无提示词自主七步思维链** —— **目标**：把七步推理结构**训练进权重**，推理时不再拼提示词模板。
   路径：自有模型 STaR 自蒸馏（生成 → 答案过滤 → 再训，用自己的模型当老师，不碰蒸馏禁令）。
   **现状**：推理引擎仍是提示词注入式（level≥2 拼接七步标题），隐式化待 Stage-2（1B）跑通后启动。
2. **无 AI 味** —— 真人写实金标 + 偏好对 DPO + 盲测 KPI
3. **反脸模** —— 跨种子 ArcFace 余弦可测量上限，同一提示词无限次生成不出现同一张脸

## 快速开始（复现 Stage-1）

完整步骤见 **[`docs/REPRODUCE.md`](docs/REPRODUCE.md)**：含语料获取与许可确认、parquet→jsonl 转换、
验收口径，以及「**哪些性质保证可复现、哪些绝对值会因语料不同而变**」的诚实边界。

```bash
# 依赖：torch（CUDA 或 CPU 均可），其余为 Python 标准库
python stage1/train.py --corpus <你的语料路径> --steps 20000 --device cuda

# 四判据验收（②③④ 硬判据，① full run 才判定）
python stage1/verify_stage1.py --mode full
```

设备无关：没有 CUDA 也能跑（`--device cpu`），只是慢。

## 数据准入原则（我们对自己也严格）

- **基座语料**：只用可商用的开源人类语料，按来源逐条登记许可与等级（License Ledger）
- **蒸馏禁令**：不允许用外部模型生成数据训练自己的模型；外部模型仅作评测参照
- **SFT / 人格 / 七步链**：永远纯人工 + 自有模型 STaR 自产
- **诚实陈述**：所有数字带口径（样本量 / 时间 / 来源）；未实测项明确标注「未实测」
